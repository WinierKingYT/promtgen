# Legacy Web Prototype

Bu uygulama PromtGen’in eski onboarding yaklaşımını koruyan tarihsel bir deneydir.

- Üretim ürününü temsil etmez.
- Kök `apps/*` workspace kapsamına dahil değildir.
- Ana build, test ve ekran görüntüsü akışlarında kullanılmamalıdır.
- Başlangıçta `projectType`, teknoloji yığını ve editör seçtiren yaklaşımı yalnız geriye dönük inceleme için saklar.

Güncel ürün girişi `src/react/main.tsx`, ürün sözleşmesi ise `src/v4/product/product-contract.ts` dosyasındadır.
